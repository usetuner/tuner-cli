# Security policy

## Reporting a vulnerability

Please do not open a public issue, discussion or pull request for a security problem.

Report it privately through GitHub: [open a private vulnerability report](https://github.com/usetuner/tuner-cli/security/advisories/new).

Include:

- what you found and its impact
- the steps or command to reproduce it, with the CLI version (`tuner --version`) and Node version
- any request ID from an error message

Never include a real API key, call transcripts or customer data in a report. Redact them first.

We aim to acknowledge a report within 3 business days and to keep you updated until it is fixed.

## Supported versions

Only the latest released version gets security fixes.

## Scope

In scope: this CLI, including how it stores and sends your API key and what it prints.
Issues in the Tuner API or web app are also welcome here and will be routed to the right team.
